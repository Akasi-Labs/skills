# akasi-research-report

Ask a real question — get a structured research report back. Pulls multiple web sources, synthesizes findings, surfaces counter-evidence, and assigns a confidence level. Pick your depth: quick (3 sources), standard (5), or deep (10+). Closer to a memo than a Google search summary.

## Install

```bash
cp -r akasi-research-report ~/.claude/skills/
```

Then restart Claude.

## Trigger

Say one of: "research [topic]", "build a research report on", "what does the evidence say about", "research deep dive", "look into [topic]".
