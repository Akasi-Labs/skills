# akasi-newsletter-digest

Pass a list of URLs — newsletters, blog posts, articles — and get a daily-briefing digest back. Each source gets a 1-line summary, key insight, and why-it-matters. Then a synthesis layer surfaces the top 3 themes across all sources, one contrarian take, and one action item.

## Install

```bash
cp -r akasi-newsletter-digest ~/.claude/skills/
```

Then restart Claude.

## Trigger

Say one of: "digest these articles", "morning briefing on [URLs]", "newsletter digest", "synthesize these links", "daily briefing".
