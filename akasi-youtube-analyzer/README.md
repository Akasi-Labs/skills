# akasi-youtube-analyzer

Pass a YouTube URL — get back a transcript summary, audience sentiment from the comments, the most-asked question, and the content gap the audience wants filled. Use it for competitive research, content ideation, or evaluating a creator before you book or partner with them.

## Install

```bash
cp -r akasi-youtube-analyzer ~/.claude/skills/
```

Then restart Claude.

## Trigger

Say one of: "analyze this youtube video [URL]", "what's the audience saying about [URL]", "youtube comments analysis", "summarize this video", "content gap on this video".
