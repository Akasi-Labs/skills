# akasi-people-extractor

Pull every person mentioned in a text source — article URL, pasted text, or email thread — into a structured list with name, role, company, context, and source. Optional: append the rows directly to a Google Sheet CRM. Useful for harvesting contacts from press coverage, conference recaps, or research dumps.

## Install

```bash
cp -r akasi-people-extractor ~/.claude/skills/
```

Then restart Claude.

## Trigger

Say one of: "extract people from [URL]", "who's mentioned in this", "pull contacts from this article", "build a contact list from", "people extractor".
