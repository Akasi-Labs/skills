# akasi-watchpage

Track changes to any webpage over time. Pass a URL — Claude saves a snapshot locally, diffs it against the previous snapshot, and reports what changed and why it matters. Good for monitoring competitor pricing pages, jobs pages, docs, or anything else that quietly shifts.

## Install

```bash
cp -r akasi-watchpage ~/.claude/skills/
```

Then restart Claude.

## Trigger

Say one of: "watch this page [URL]", "track changes to [URL]", "what changed on [URL]", "diff this page", "monitor this URL".
