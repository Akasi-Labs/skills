# akasi-tldr

Pass any URL — get back a 3-sentence executive summary, 5 key takeaways, and one action you could take based on the article. Replaces the "open it later" tab with a 30-second decision.

## Install

```bash
cp -r akasi-tldr ~/.claude/skills/
```

Then restart Claude.

## Trigger

Say one of: "tldr [URL]", "summarize this article", "what's this page about", "give me the gist of [URL]".
